# 卡片表面规范

> 2026-09-10 用户确认，D17。当前深色方案的公共默认规则，替代此前无描边和强描边两种尝试。

## 适用范围

凡表达独立内容单元的 Card 概念容器均采用此配方，包括通用 Card、Widget / Dashboard 面板、资源卡片、审核卡片，以及调用时间线、调用关系树、minimap、Span Passport 等大型组件。由用途判定，不依赖组件是否命名为 Card。

页面背景、布局占位容器、无外框列表、按钮、输入框、图中的节点和边不自动变成 Card。DSH Composer 等宿主组件继续由宿主定义，不覆盖其样式。

## 默认配方

| 项目 | 规则 |
|---|---|
| 表面 | 比页面稍亮的 `--color-background-card`，当前 `#232324`；内部内容按既定表面层级使用灰阶 |
| 圆角 | `--shape-panel`，当前 12px；沿用已确认的特殊尺寸配方，不因移除描边而去掉圆角 |
| 边框 | 1px solid `--color-border-subtle`，当前 `#ffffff0f`，约 6% 白色 |
| 阴影 | `0 4px 12px 0 #00000005, 0 2px 8px 0 #0000000a`，两层轻微黑色阴影 |
| 留白 | 使用组件自身 padding 与公共间距；边缘交互不得被圆角裁切 |

灰度底色负责区分表面，低对比边框勾出轮廓，淡阴影辅助层次。不得把 default / strong 边框重新全局应用于所有卡片。不要叠加多层重复阴影，也不要把全部嵌套布局都包装成卡片。

选中、拖放、错误和键盘焦点继续使用已有语义状态规则；其高对比提示不被默认卡片规则抹掉。内部表头分隔、图表网格和节点状态线条继续归对应组件。

## 大型 Trace 组合

调用缩略图与调用时间线组成左列，宽度一致；调用详情占右列完整高度。缩略图 zoom 区域右侧留 6px；上下各 6px，避免滑柄、时间刻度触碰外层圆角。目录动画期间保持同样的边距和对齐。

## 实现与验收

公共样式见 `wsr-ui/packages/bi/src/card-surfaces.css`；通用 Card、Widget 和 Trace 表面复用同一规则。原型调色器不得将它覆盖成 16% 白色强边框。

检查最终计算样式：边框 1px / 约 6% 白色、保留圆角和两层淡阴影；再检查选中 / 焦点状态仍清晰，宿主 Input 不受影响，缩放控件不被裁切。文档规则已确认；历史来源快照不重写，尚未重新生成的旧资产不能覆盖本规范。
