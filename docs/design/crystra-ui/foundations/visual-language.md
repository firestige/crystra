## 视觉方向

深色专业工作台：近黑 Shell、轻微分层的面板、细边框、紧凑文字；蓝色表示交互焦点及运行，绿/黄/红用于状态。把有限亮度分配给当前问题、异常、选中对象与关键输入。晶体标志用于品牌，不给每块正常信息添加发光效果。

三个 v6 共同呈现暗色多栏、持续 Input、审核卡和证据细节的方向。其线性 Define→Accept 步骤、右侧接受/发布按钮、Library 与大品牌卡片均不能进入当前规范。[原图与稿件](../assets/README.md)

## 字体、间距与形状

A1 的字体声明为 `Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`，未提供 Inter 字体文件；渲染可能使用系统字体。中文实际字形按系统回退，验收需覆盖双语与字体缺失。

原型常用正文 14px、次级内容 12px、微型标注 10–11px（Tailwind 默认基准为 16px 时的展示值）。主内容间距以 12/16/20/28px 为主；常用卡片圆角 12px，Composer 16px，轻量按钮 6–8px。小字用于原型密度验证，不据此宣称全部可读性合格。

阴影原值 `0 18px 45px rgba(0,0,0,.24)`。品牌行透明、无大面积卡片背景；选中工作面采用 12px 圆角、accent 细边框与同色 12% 背景，不用下划线。Hover 不改变元素宽度或布局。

## 图标与状态

品牌是自有约 24px 晶体标志。折叠 Chevron 使用等尺寸 SVG 旋转；运行身份复制及反馈统一归入行内工具档位，用户最新裁定取消 U1 的 15 / 30px 特例，具体尺寸见 [已接受图标规范](iconography.md)。其他图标统一具体资源家族属于待选资源项，不能从原型 Unicode 符号推导已选图标库。

颜色必须与文字、线型或形状共用。Task 行状态优先级：失败停止 > 待审核 > 运行中 > 工作全部完成。黄色速度偏离与黄色 Gate 不得只有同色而缺少标签。图状态细节见 [图投影](../components/graph-projections.md)。

## 可访问性检查边界

采用 skill 的键盘、焦点和 reduced motion 检查方法；具体约束优先遵守 U1。复制按钮已按用户裁定统一为 28px 工具点击区；首期桌面场景不套用移动端 44px 命中区建议。触摸命中区、文字对比度、200% 缩放和窄窗口可读性作为待验证项，不能宣称已通过 WCAG 或移动适配。

当前沿用深色基线；[页面五色语义](color.md) 已按用户要求收敛为中性灰、蓝、绿、黄、红，通过亮度和透明度派生角色；图表配色独立，v8 固定已接受样式。浅色 token 和完整图标集均未定稿；字号已按用途归类，并在 [语义化字体基线](typography.md) 记录已选定 B「均衡」的字号、字重与行高基线；D03 明确移动端布局不在本阶段范围。Sidebar v8 的折叠视觉、图标导航与抽屉动效已获用户确认；生产资源及宿主图标替换见 [遗留待办 L02](../deferred-todos.zh-CN.md)。配色以语义归并为目标，不增加换肤方案。
