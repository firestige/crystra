## 选择表

| 表达方式 | 适用问题 | 内部数据形状 | 固定构图 | 建议尺寸 |

| 单状态 | 现在是什么状态 | 对象、枚举与显示标签 | 对象图标、居中短状态；辅助状态在右上角 | 1×1 |
| 单量值 | 现在是多少 | 对象、数值、单位 | 1×1 为对象图标、居中数值和单位；1×2 为可见标题与数值、单位 | 1×1 / 1×2 |

| 目标进度 | 距明确目标还有多少 | 当前值、目标、单位 | 当前/目标、剩余量、单条进度bar | 1×2 |
| 单一份额 | 当前部分占总体多少 | 部分值、总体值 | 一个ring，中央百分比，下面分子/分母 | 2×2 |

| 总体构成 | 总体由哪些部分组成 | 总量、互斥部分、标签 | 总量、分段条、数值图例 | 2×2 |

| 区间指示数字 | 当前值是否偏高或偏低 | 数值、单位、正常区间、评价 | 居中对象图标；数值、单位与箭头整体居中；标题和正常区间用 Tooltip，不重复偏高文字 | 1×1 |
| 仪表盘 | 当前值在正常范围中的位置 | 数值、量程、范围分区 | 分区着色表盘、指针与精确数字 | 2×2 |

## 外框与共同视觉

尺寸为行×列。含 border 和 padding 的宽度为列×160+(列−1)×16px，高度为行×160+(行−1)×16px。1×1=160×160，1×2=336×160，1×3=512×160，2×2=336×336，2×3=512×336，3×3=512×512。

状态、量值、进度等紧凑 Widget 只开放声明的离散尺寸。图表声明的是最小行列数，预设尺寸是快捷项，不是完整枚举；用户可输入任意整数行列，只校验不小于该表达的最低容量，不设置组件级上限。超过当前可见网格宽度时由 Dashboard 提供局部横向滚动，不压缩单元尺寸。普通 Card 不继承此约束。

沿用现稿圆角12px、基础 padding12px；标题14/20px、字重400，中英文一致。组件颜色、字体角色沿用 foundations 和已导出资产。紧凑配方以主体图标、内容、辅助状态组成，不默认添加操作栏或底部占位。

## 固定主次与复用边界

1×1 的 1、2、15 号样本采用右上角辅助状态：18px 状态图标悬浮定位，保留 Tooltip，不再占据底部一行；48px 对象图标与主内容水平居中，整体相对几何中心下移 6px，以校准上窄下宽构图的视觉重心；右上角状态位置不变。此位置与视觉校准已确认。Widget尺寸均含跨格16px间距；普通Card不套用这些尺寸。

主内容回答一个问题；标题说明对象，单位/刻度帮助读数，状态说明可信度。身份、长解释、证据明细等不堆进Widget。样本没有默认action，实际可选动作必须有明确用途。

目标进度和份额可以都是比例，但前者回答距离，后者回答占有；因此本稿分别给bar和ring，同类数据允许用途明确的固定表达变体；区间数字强调精确读数和偏离，仪表盘强调范围位置。分类横条回答比较，总体分段条回答构成。时间柱回答每期量，直方柱回答数值分布，不能按“都有柱子”合并成同一种语义。

## 图形选择的当前建议

单份额与多部分构成保留各自数据语义。构成支持分段条、饼图及环形，使用同一份部分值与总量。雷达图用于两个方案的多维能力轮廓比较：共享维度与 0–100 评分量程，向外统一表示更优。使用蓝色实线圆点和橙色虚线方点，配同形图例。不同单位的原始指标须由适配层按明确口径转为可比评分，不能直接混用，也不以多边形面积推导总分或优胜结论。

短文本不等于文档卡；只容纳一句活动、结论或当前选项。多个互不相关的指标不是单个Widget。完整表格、Evidence、Inspector、瀑布与树仍由专业视图或普通Card承担。

## 语义关联、表达变体与尺寸

Widget 是具有稳定数据身份的展示单元，表达方式与尺寸是它的变体。18 个示例用于展示配方，不等于 18 个互不关联的 Widget 类型。数据语义、表达、容量共同决定渲染。

| 语义家族 | 数据身份与形状 | 表达变体 | 尺寸与信息层级 |
|---|---|---|---|
| 活动与状态 | 对象、状态、当前活动、上下文 | 状态摘要 / 状态及活动详情 | 1×1 图标与短状态；1×2 保留原状态，再补充已有活动主句与上下文 |
| 单量值 | 同一个指标的数值、单位；可附正常区间、量程、目标或分母 | 数字、区间箭头、条形、环形、仪表盘 | 数字 1×1 / 1×2；区间 1×1；条形 1×2；环形 2×2；仪表盘 1×1 / 2×2 |
| 单序列 | 标签、同单位数值、顺序含义 | 折线、柱状、横向条形 | 2×3；切换保留标签、单位、顺序和数值 |
| 总体构成 | 互斥部分与共同总体 | 分段条、饼图、环形构成 | 2×2；保留各部分颜色、名称、数值与百分比 |
| 区间分布 | 原始区间边界与对应频数 | 直方图、区间中点频数折线、频数表 | 2×3；保留所有区间与计数，不变成时间序列 |
| 二维覆盖率 | Workflow × 日期、百分比及缺值 | 热力图、多序列折线、分组柱状图、分组条形图、数值表 | 2×3；日期顺序、对象名称和缺值保持不变 |
| 多维方案比较 | 方案 × 评价维度、同量程评分 | 雷达图、分组条形图、热力图、数值表 | 雷达 2×2；其余 2×3；保持每个方案每个维度的分数 |

数值变体共用数据，不能切换成另一项指标。42 ms 改为仪表盘仍是 42 ms；检查单 6/8 改成环形显示 75%，标题与分母仍指向检查单。区间指示需要明确正常区间；条形 / 环形需要目标或分母；仪表盘需要量程。缺少这些内部字段时不虚构参数，相应表达不进入菜单。这是表达适配条件，不要求后台就绪。

序列的时间、阶段和类别含义保留。折线需要有意义的顺序；无序类别可以使用柱状或横条。切换阶段耗时的图形不把阶段标签变成小时，不生成新的聚合。数值分布的区间与频数、热力图的二维关系、状态历史的时间区间、雷达图的多维对照各保留其结构，不因图形相似而与单序列混淆。

上述表格只定义可用表达及容量。切换时的实例、状态和保存规则只见 [组件契约](widget-component-contract.md#稳定实例与切换)，右键菜单和布局反馈见 [Dashboard](library/dashboard.md)。

实现入口：widget-families.ts 定义数据家族与可用表达；SemanticWidget 固定渲染这些关联家族；ExpressionWidget 为展示入口；Dashboard 与独立示意复用同一渲染。示例数据由独立 fixture 提供，表达选择不替换 fixture。其余专业表达继续复用原固定配方。普通 Card 与专业详情不继承 Widget 尺寸。

## 内容保真

状态与活动是独立字段。“运行中”不等于“验证构建产物”；样例只是同一对象的两个已给定字段。扩展容量保留状态并展示已有活动信息，缺少活动或上下文时不编造内容，也不从状态推断具体活动。

样式由当前表达、尺寸和槽位角色决定，示例身份不参与样式选择。切换生命周期见 [组件契约](widget-component-contract.md#稳定实例与切换)。

缺值不是零：二维折线在缺值处断开，表格明确标记无数据；雷达只在所有维度都有评分时可选，避免用零补出伪轮廓。


辅助事实状态使用可读 Tooltip，不直接显示枚举 key。当前图标映射：可用 circle-check、仅下界 circle-arrow-up、不适用 circle-minus、不可用 circle-x、已过期 clock、不兼容 exclamation-circle；使用已有圆形 Iconify 图标，不额外嵌套圆圈。该风格不覆盖涨跌三角或对象身份图标。

### 观测总览中的时间堆叠与来源标识

时间 × 可加分项的矩阵可声明 `stackable: true`，在分项非负且完整时提供 `stacked-columns`（最小 2×3），与多序列折线、分组柱状图、分组条形图和数值表共享原数据。堆叠高度按同一时间点的分项累计绘制。比率、重叠总体或不可相加的矩阵不声明此能力。来源可提供固定系列颜色，使同一 Provider 在多个图表间保持一致。数值表允许附带每格样本数；图例使用数据语义名称，不把任意矩阵固定称作覆盖率。

折线、柱状图与热力图必须显式持有数值范围策略：`auto` 依据当前数据的最小值、最大值及留白计算范围；`zero` 将零纳入范围；百分比可选 `full` 固定为 0—100%；`custom` 保存用户输入的有限上下限且要求下限小于上限。折线使用该范围作为 Y 轴，热力图使用同一范围映射色标。时间序列与热力图默认 `auto`，避免窄幅变化被从零开始的量程压扁；表示绝对规模和可加总量的柱状图默认包含零。范围策略随 Widget 保存，数据更新时 `auto` 重新计算。

观测总览的金额、估值、API 调用、Tokens 用量汇总使用 1×2 数字表达，直接展示标题、数值与单位；切换为 1×1 时沿用对象图标与 Tooltip 规则。缓存小表盘按 Provider 使用一致来源颜色，表盘结构和尺寸沿用既定表达。

观测查询预览将按来源的周期比较适配为单列矩阵，复用分组条形、分组柱状和数值表；缓存命中率共用 0—100% 量程。按日查询适配为时间矩阵，复用多序列折线；可加量允许堆叠，百分比不允许堆叠。指标、来源筛选和聚合由宿主查询层确定，不按 Provider 新增 Widget 类型。
