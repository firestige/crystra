## 职责

Agent 将用户意图写成语义 JSONIR。引擎解析并诊断结构、生成展开／折叠投影，再交 ELK 计算层级、位置与正交连线。Viewer 负责选择、缩放、搜索、聚焦与层级操作，不将坐标写回 IR。

JSONIR 不等于可执行 Workflow DSL。这里定义面向用户的活动与关系；未来编译与 Execution 的绑定、资源准入、正式版本发布必须服从相应 owner。当前引擎不包含任何 Implementation 名称、活动 ID 或按样例配置的坐标表。

## 当前候选语义

- 顶层：`version: "0.2"`、title、可选 description、nodes、edges。
- 活动：稳定 id、kind、title、可选 parent、description、inputs、outputs、resources。
- kind：start、end、activity、decision、fork、join、group；join 另声明 all／any。
- parent 只表达包含关系，必须指向 group，不能循环。
- 连线：稳定 id、from、to、可选 label、summaryLabel、kind（control／material）、intent、trigger。关系必须指向明确内部活动，不能把 group 当成含糊的可执行端点。
- 数组顺序用于稳定阅读偏好，不定义执行顺序。条件与并行由关系和类型表达。
- Agent 不能提交 x、y、width、path、CSS 或其他未定义字段。生成几何独立于原始定义。

[校验与投影源码](../../../../wsr-ui/packages/bi/src/domain/workflow-map-ir.ts)是当前原型实现；本候选仍需继续评审多入口、条件形式化、材料端口、资源身份和版本引用，不借界面原型单方面发布系统契约。

## 分层与聚焦

展开 group 显示嵌套容器与内部活动；折叠时由引擎将外部可见端点投影至最近折叠祖先。每条连线保留原始 id 与真实端点，多个跨层关系不会被合并成一条无来源关系。完全位于折叠范围内的关系暂不画出，原始 IR 保持不变。

关系详情显示真实起止活动，可直接定位来源／去向。搜索深层活动时自动展开祖先；面包屑显示完整包含路径。活动详情可突出当前路径视角下的可达上游，非关注内容减淡，不从模型中删除。折叠／展开／聚焦均不改变工作流内容。

初次打开及切换样本呈现顶层总览，默认横向布局。视口是独立镜头：按目标包围盒与当前可显示宽高计算缩放、居中偏移，四周预留 48px，放大不超过 140%。点击展开后以该步骤的新包围盒取景，收起后以父层上下文取景；搜索定位后以目标取景，详情栏改变可用宽度时重新计算。手势与镜头使用项目已有 D3 zoom，程序化取景使用其 560ms smooth zoom transition，替代 CSS transform 过渡，遵守系统减少动态效果设置。“适应当前层”仅重新框住当前 scope；“全图概览”单独展示全图，不擦除记住的焦点；“返回焦点”恢复最近聚焦对象与当时展开层级。手动拖动／缩放不会改变焦点。面包屑可逐层取景。D3 处理拖动、滚轮缩放与触屏捏合，手势可中断程序动画，遵守减少动态效果设置。布局不写回语义定义；镜头不能消除布局长宽比本身的失衡，因此逐层展开承担细节控制。当前布局节点重新排布尚未逐节点插值，镜头过渡与几何形变是不同能力。

默认路径视角为“预期路径”，已声明的返工、恢复和退出关系及其专属活动减淡保留；“全部路径”恢复完整呈现。未分类关系保持中性，并在检查中报告待确认，不能猜作 happy path。选中节点后，在当前视角的控制流中反向遍历真实 IR，再投影至当前层级。预期视角仅沿明确的 expected 关系追溯；全部视角保留返工循环与跨层关系，可能覆盖较大范围。材料关系不等同控制流可达性。选择复合活动时以内部活动集合为目标。取消突出与切换路径视角是独立操作。

## 预期推进与保障语义

这是 0.2 候选的可选字段扩展，旧输入仍可查看，不自动迁移其语义。

| intent | 用户名称 | 含义 |
| --- | --- | --- |
| expected | 预期推进 | 正常计划的一部分，可包含选择、并行、正常迭代 |
| rework | 返工 | 因成果不符合要求而重新处理 |
| recovery | 恢复 | 应对缺失、异常或环境偏离，尝试继续工作 |
| exit | 退出 | 按明确条件离开当前流程，可用于失败或人工终止 |

intent 只适用于控制流。保障关系必须给出非空 trigger，说明触发原因或处理完成后的衔接条件；它目前是供审查的自然语言，不是可执行布尔表达式。label 仍是图中显示的分支文字，不能代替明确的意图声明。关系详情显示意图与触发条件。

分类由 Agent 按用户意图提出、用户通过候选定义确认；引擎不根据方向、名称、“失败”一词或循环推断。开发样本将正常 TDD 实现迭代、逐单元迭代声明为 expected，将回归失败与交付复核失败声明为 rework；这些是样本作者决策，不是引擎规则。

当前新增静态诊断：
- UNCLASSIFIED_FLOW：控制流未声明意图，warning，要求进一步确认；当前不阻止发布演示。
- MISSING_TRIGGER：明确声明的保障关系缺触发说明，blocking。
- NO_EXPECTED_COMPLETION：控制流全部完成分类，但起点沿 expected 关系不能抵达任何结束节点，blocking。该检查只证明结构上存在结束路径，不等于成功验收或必然终止。

错误不妨碍保存合法结构的草稿。静态检查用于尽早发现明确错误，不作“没有运行期错误”或“不会泄露”的保证。后续再扩展前置条件、完成判据、不变量、重试预算耗尽去向与并行退出规则；这些尚未实现，不在本版发布检查能力声明中。条件覆盖、实际终止性、信息访问权限、运行期异常仍需相应的形式化模型及执行期机制。

## Agent 验证台

右上角帮助图标打开「设计验证台」，这是本轮评审工具，非最终业务表单。提供开发、系统设计、科研管理三份含循环／分支／并行／层级的纯语义 JSON 样本。切换样本时同一组件、同一引擎重新计算，Header 名称与描述同步。

可以直接提交任意 JSONIR。语法、schema、引用和层级错误明确列出路径，保留当前有效图。合法定义先试布局；布局失败不替换当前图。结构合法但内容不完整时允许展示草稿，诊断继续挂在相关活动上。

当前 Chat 适配仅支持通用演示指令「展开 名称」「聚焦 名称」「定位 名称」「把 原名 改名为 新名」。重命名产生完整候选 JSONIR，先预览，再采用。其他输入明确说明未接正式 Agent。真实 Agent 不必受这几个演示指令限制，只需按协议输出语义定义。

## 检查与版本

结构入口拒绝错误类型、未知字段、重复身份、悬空关系、无效父节点、层级循环与含糊的 group 端点。可渲染语义诊断包含：入口／终点缺失、不可达活动、无法到达终点、结束后继续、缺条件的判断、未明确并行与汇合规则等。

保存草稿不被语义缺口阻断。本地保存当前定义，验证台可读取。发布模态对当前内容重新检查；阻塞项存在时不能创建只读演示版本。创建时复制内容，不改变草稿。当前演示版本不发布实际资源、未持久化正式版本目录，也不证明循环一定终止、材料类型相容或资源／Execution 准入通过。

## ELK 与视口接入约束（2026-09-11 修订）

仍由 ELK Layered 负责节点位置及正交路由，不自行寻路，不把贝塞尔曲线作为连线。每个嵌套容器按当前可用主轴尺寸与直接子节点数计算基础间距：跨层节点间距 clamp((主轴可用尺寸−96−节点数×160)/(节点数−1),32,80)，同层间距为基础值的 70% 且不小于 32；边与节点 28、边与边 20。不能假设根配置自动覆盖全部内部图。容器内边距上 52，其余 28，根留白 24。普通活动最小宽 160、高 88，标题字体保持 17，不通过改变字体大小压缩布局。连线标签按 98 的内容宽度折行，ELK 按完整标签块尺寸避让，防止长说明横向撑开整张图。视口改变时重新布局，并继续检查节点、箭头与标签的必要空间。这些是当前候选几何配置，非用户业务字段。

每条可见边的输入／输出端分别拥有独立 FIXED_POS 端口，不再让整个节点共用一进一出。整体方向只约束主流程排列，不限制端口方向。先由 ELK 生成相对位置，再由适配层根据主轴位移与横轴位移选择四侧端口，第二次由 ELK 完成布局和正交路由：逆向边两端使用同一横向侧面以形成外围回路；正向边的横轴位移超过主轴位移的一半时使用相向横侧连接，其余保留主轴连接。横向图允许上下接线，纵向图允许左右接线。这是候选几何策略，不是 ELK 自动最优选侧的承诺。同侧端口按稳定的边顺序居中分散，间隔上限 28，避开两端各 16 的角区。端口只是引擎适配层的几何，不进入语义 JSON IR。菱形、圆形按真实轮廓计算连接点，并使用 ELK port.borderOffset 的负偏移贴合轮廓，不能仅指定内缩 x/y（ELK 会把它归回矩形边界）。每层显式关闭 layered.mergeEdges 和 layered.mergeHierarchyEdges，避免独立控制边在跨层边界被合并。路径仍完全使用 ELK 的正交路由结果，不在渲染阶段手工改线。箭头 markerUnits 使用 userSpaceOnUse，10 个图坐标单位，不随选中线宽额外放大。验证正交、节点不重叠、端点贴合及末段至少 24 的箭头余量；不能只验证 DOM 有节点。

库职责分离：ELK 负责布局／路由；D3 zoom 负责手势、视口状态与平滑相机插值；React 负责语义选择、记忆焦点与显示。React Flow 的 fitBounds / fitView 区分作为交互参考，未声称本版已迁移至 React Flow。

参考：[ELK spacing](https://eclipse.dev/elk/documentation/tooldevelopers/graphdatastructure/spacingdocumentation.html)、[ELK port constraints](https://eclipse.dev/elk/reference/options/org-eclipse-elk-portConstraints.html)、[D3 zoom](https://d3js.org/d3-zoom)、[React Flow viewport API](https://reactflow.dev/api-reference/types/react-flow-instance)、[Mermaid layout configuration](https://mermaid.js.org/config/layouts)。

## 退出、同级切换与空间导航（2026-09-11）

- 单击活动与键盘 Enter／Space 共用选择逻辑：选中、突出上游、打开详情，同时镜头定位该活动。不能只改变高亮而仍以旧步骤取景。
- 展开复合活动进入其内部；收起则退出到父层上下文，顶层活动收起回到工作流总览，并关闭旧详情与路径突出。另设“返回上层”；从普通活动退回包含它的层级，从展开的复合活动退出时收起该活动。
- 左侧“大纲”通过既有 sidebar icon button 开关，240ms 展开／收起，默认隐藏，不抢占初始画布。仅显示 kind=group 的复合步骤，叶子活动不进入导航大纲；使用语义包含关系显示可折叠列表；大纲的展开只影响列表，点击条目才自动展开图中所需祖先并定位。定位复合活动时展开它，定位普通活动时只展开祖先。隐藏大纲不可被键盘聚焦。
- 缩略导航图位于画布右下角，200×128，沿用共享 card 的灰度、弱边框和阴影。投影当前完整布局，视窗矩形对应主画布真实的相机坐标和可显示尺寸；包含层级、节点和连线，不另运行布局。
- 点击缩略图平移主视口至该位置，拖动视窗保留抓取偏移，方向键以当前视窗宽高的 20% 移动。手动导航保持缩放、选中、路径模式及语义定义不变，不覆盖记住的焦点；“返回焦点”仍可回到原目标。缩略图指针位置使用 SVG 屏幕矩阵逆变换，避免长宽比留白导致定位偏差。

回归场景：进入理解与设计 → 收起回父层 → 单击逐单元实现 → 相机目标为 work；大纲定位深层复合步骤 → 自动展开祖先；缩略图移动 → 返回焦点恢复原取景。

2026-09-11 header 收敛：镜头、展开／收起、路径／方向、草稿与发布操作统一到页面 header 右侧，复用 ghost icon action，不保留绘图区底部工具栏。路径和方向 SelectField 调用 menuPlacement="top"，优先向上，空间不足由共享 picker 翻转避让。叶子活动继续通过图或搜索选择。

Header 图标操作必须显示与 aria-label 一致的可见 tooltip，复用现有 WidgetTooltip（portal 防裁切、悬停／键盘聚焦、Escape 关闭）。禁用操作通过外层可聚焦触发器仍能读到名称，不重复叠加原生 title。百分比按钮提示“恢复 100% 缩放”。

## 活动图形状与层级控制语义（2026-09-11）

形状表达语义，而不是为每个步骤分配一种外观：普通活动为圆角矩形；复合活动仍为圆角矩形，仅以 chevron 表示可展开／收起，移除重复的子流程“+”标记；判断为菱形；并行分叉与汇合为控制条（方向跟随图布局，文字在条外）；起点为实心圆，正常完成为外环加实心内圆，终止退出为圆内叉号。三个复合步骤共享同一种形状与颜色。该候选是面向用户的图形语法，不宣称完整实现 UML 或 BPMN 标准。

分层是抽象与封装边界，按类似代码架构的方式逐层阅读。父层描述阶段职责、调用关系、对外结果以及属于父层的控制判断；子流程内部活动、循环、条件分支默认留在该子流程。内部判断影响阶段结果，并不构成提升到父层的理由。进入、退出和同级切换分别对应下钻、返回调用层和切换当前抽象对象；不默认展开所有层级。

当前开发样本的顶层为：理解与设计 → 逐单元实现 → 测试与复核 → 整体测试通过？；通过后完成，未通过根据已声明条件回设计、回实现或退出。顶层判断的分支条件表达失败原因／终止决定。材料澄清留在设计内部；逐单元循环留在实现内部；TDD 位于实现下一级；并行复核与结果汇总留在测试内部。实现和测试内部各自仍可有验证判断，不与顶层验收混淆。

撤销 HIDDEN_BOUNDARY_DECISION 提升建议：这是错误的抽象规则，不继续作为检查项。形式化检查应针对当前层及其跨层契约，不能要求暴露全部内部实现。正式的输入、产出、前后条件和结果端口契约尚待设计，当前候选不能宣称已经完成这些校验。

控制边增加可选 summaryLabel：端点因折叠映射到复合活动时，显示作者声明的阶段结果，例如“设计完成”“实现完成”；展开到实际端点后仍显示原始 label。连线身份、真实端点、原始条件和意图始终保留。引擎不自动前缀内部判断名称，不猜测“有／无”含义，不为任何具体业务硬编码展开策略。summaryLabel 只用于抽象层的阅读，不重写或替代原始控制语义。

颜色资产为 [workflow-map.tokens.json](../assets/workflow-map.tokens.json)，源码为 wsr-ui/design/workflow-map.tokens.json。按语义类型定义 fill/accent：活动青绿、复合活动蓝、判断琥珀、并行控制紫、起止各自配色。深色填充、淡边框与原有阴影配合；类型色不代表运行成功、失败或审批状态。颜色是形状的辅助，不能替代形状；以后主题按同名语义 token 覆盖。

### 端口分散的参考与限制（2026-09-11）

[Archify geometry.mjs](https://github.com/tt-a1i/archify/blob/main/archify/renderers/shared/geometry.mjs) 的 automaticPortSpread 按节点和侧面聚合连接，依对端位置排序并分散连接点；[workflow compiler](https://github.com/tt-a1i/archify/blob/main/archify/renderers/workflow/workflow-compiler.mjs) 还评估交叉数、共享走线长度及内部短线段。它使用自己的确定性路由实现，不能称为 ELK 配置范例。本次采用独立端口、避免合并、轮廓贴合的原则，继续由 ELK 布局。当前端口排序采用稳定 IR 边顺序，尚未引入 Archify 的候选布局评分或依对端位置二次排序；不宣称复杂图从此零交叉、零重叠。

[ELK mergeHierarchyEdges](https://eclipse.dev/elk/reference/options/org-eclipse-elk-layered-mergeHierarchyEdges.html) 默认 true；这是跨层级连接的合并策略，不是所有节点默认只能一进一出。[port.borderOffset](https://eclipse.dev/elk/reference/options/org-eclipse-elk-port-borderOffset.html) 允许负值把端口移向节点内部。回归覆盖开发样例横／纵、展开／折叠下每个多入／多出节点的端点唯一性，另保留三类流程的节点不重叠、正交、菱形轮廓与箭头余量检查。

四侧端口回归补充：横向与纵向总览的返工边均验证首、末线段垂直于主布局方向；原有轮廓贴合、正交和箭头余量检查继续适用。两次布局使用独立输入，避免第一轮 ELK 写回的边段污染最终路由。

### 结果语义、路径色与焦点阅读（2026-09-11）

候选 JSON IR 的 end 节点增加可选 outcome: completed | terminated；省略兼容为 completed，只允许在 end 上声明。样例的退出节点明确声明 terminated，不从 title 或节点 ID 推断。正常完成为绿色终点环，终止为红色圆内叉；两者都结束当前设计流程，但结果语义不同。这是 Crystra 候选图形语法，不等同于 UML flow final 的执行契约。

| 连线意图 | 语义 token | 冗余辨识 |
| --- | --- | --- |
| 预期推进 | --workflow-flow-expected | 青绿实线 |
| 返工 | --workflow-flow-rework | 琥珀长虚线 |
| 恢复 | --workflow-flow-recovery | 紫色点划线 |
| 退出 | --workflow-flow-exit | 红色短虚线 |
| 材料关系 | --workflow-flow-material | 蓝色虚线 |
| 未分类 | --workflow-flow-unclassified | 中性灰实线 |

箭头跟随线色；hover、选中及上游强调通过线宽和透明度表达，不把语义颜色全部改成蓝色。预期路径模式减淡保障路径但仍保留可辨识色，标签继续说明条件，不能只靠颜色表达。终点使用 --workflow-end-* 与 --workflow-terminated-* 两组 fill/accent token，不表示实时执行状态。

聚焦展开的复合活动时，只显示该活动及其后代、内部关系，层外元素不可点击；它们仍保留在完整布局与缩略图中。退出、全图概览恢复上下文。用户主动拖动、滚轮或缩略图移动会解除当前层视觉隔离，同时保留已记住的焦点，避免导航到空白世界；返回焦点重新取景并隔离。收起／展开仍有既有镜头动画。有限宽度无法保证任意规模的完整流程都在 100% 同屏显示；先消除浪费间距，再由分层阅读承担复杂度，不以无限压缩安全距离解决。
