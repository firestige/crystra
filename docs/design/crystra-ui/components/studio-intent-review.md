## 版面

保留 workflow 名称与描述、流程设计／结晶分析导航、左侧 Chat。右侧为三段：版本和发布工具、路径与搜索、活动图。详情／问题／变更共用一个可关闭的右侧面板，不常驻占用图面。

主图显示理解任务、设计方案、实现与验证、整体验收、整理交付五个阶段。展开实现与验证后显示内部四个活动；面包屑返回概览。分层只调整观察粒度。活动名称、材料、成果和工作规则面向用户，不展示 Action、Delivery、运行控制字段。

候选尺寸：图节点 180×136px，图面最低宽度 1040px，超出可用宽度横向浏览；详情面板 320px，打开后定位选中对象。图卡消费公共 Card 的灰度、圆角、弱边框与淡阴影。SearchField、SelectField、Button、IconButton、Typography、Chip、Card 复用共享控件；组件 owner 隔离旧页面适配器。

## 意图与反馈

- 选择活动展示输入、成果、约束、资源；「引用到 Chat」写入输入草稿。
- 搜索名称、描述、材料或资源可定位深层活动，并显示所属层级。
- Chat 修改先形成候选，在图上高亮节点／虚线返回路径，变更面板解释前后差异。
- 只有在 Chat 中采用建议才更新草稿；查看或收起候选不修改工作流。
- 问题显示在活动上，上层阶段汇总其内部问题；问题面板可定位活动、把补充意图带入 Chat。
- 本地演示支持「验收失败返回实现与验证」与「绑定测试编写资源」两段对话。其他输入明确说明未连接 Agent，不伪造自然语言理解结果。

## 草稿与发布门禁

草稿可不完整，保存在当前浏览器；保存失败显示状态。预置两个阻塞问题，编辑不被它们阻断。发布弹出居中遮罩模态，检查对应的确切草稿内容；阻塞项存在或检查已过期时不可确认发布。

本地演示检查两条规则：验收失败返回路径、测试活动资源是否已确定。发布处理再次比对内容身份与问题，创建独立内容副本；选择已发布版本只读，修改需返回草稿。v1 为预置版本，后续 v2 等仅在本地演示存储，不调用真实发布服务。非阻塞优化建议不能成为发布障碍。

正式产品需要把图意图编译成系统定义，对候选版本执行权威的完整检查，并在内容改变时使检查失效；版本写入、不可变性、资源固定引用与并发发布由 Workflow owner 保证。本页两项演示检查不构成 Execution 可执行性证明。

## 结晶分析

沿用同一工作流与活动图，示例通过「测试结果整理」候选定位测试活动，说明可固化部分及仍需判断的部分，带回流程设计与 Chat 讨论。不在本轮展开生产执行样本检索和实际收益估算。
