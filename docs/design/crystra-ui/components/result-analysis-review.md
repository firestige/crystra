# 对比分析：观察设置组件契约

> 更新至 2026-09-11：包含 9 月 10–11 日已确认的侧栏、三列编辑器、断点布局、指标引用与逐项编辑；2026-09-10 基本方向获确认并授权页面接入，D22。此文件保留原路径以兼容已有引用，内容已从评审候选归并为当前设计契约。
>
> [组件样本](../assets/component-preview.html#result-analysis-review)与 [Analysis v8 · 对比分析](../assets/crystra-analysis-audit-v8.html?view=reports)复用同一组件。确认视觉与交互，不代表真实查询和持久化服务已接入。

## 职责与边界

用户选择一套观察逻辑，并在全局可观测数据范围内缩小参与分析的 Delivery 集合。系统按每张图表的数据列与映射生成视图，帮助比较费用、调用、缓存和延时等差异；不生成 Workflow 结晶或编排方案。初期满足已验证需求，根据实际反馈扩充数据能力目录，不开放任意代码。

观察设置保存图表集合及其顺序。每张图表独立拥有自定义标题、数据列、类型、轴与分组映射。临时 Delivery 集合与全局时间范围不属于设置；切换设置保留本次数据范围，范围变化不将设置标记为未保存。

Delivery 是样本来源和下钻身份，不作为默认分类轴；Task 是可接续的业务上下文，不等同于单条 Trace。比较应支持多 Delivery 聚合，不将一次 Delivery 的多条调用视为独立执行样本。

## 主视图

左侧为默认展开、可收起的预制／已保存观察设置列表。点击激活，右侧显示该设置的所有图表。右侧 Header 仅显示设置标题与数据范围入口；不重复全局时间、不显示全部 Delivery 数、不放设置编辑表单或解释文案。

列表标题区复用 Action Tool（ButtonGroup、IconButton、WidgetTooltip）：修改、导出、导入、新建；28px 命中区、14px 图标、ghost 表面。帮助通过 help icon 打开模态说明。每个设置列表项右侧的 actions 提供 ghost 编辑与删除图标，编辑位于 trash 左侧；Header 不提供删除操作。点击逐项编辑直接打开该项草稿，不先激活该设置，取消保持原视图，保存后激活编辑后的设置。Header 的修改入口继续编辑当前激活项。

- 删除非当前项保持当前视图；删除当前项后激活原位置的下一项，没有下一项时选上一项。
- 全部删空后清除图表并显示新建／导入引导，修改与导出禁用，新建、导入仍可用。
- 删除设置只删除配置，不删除可观测数据，也不改变当前 Delivery 范围。
- 切换总览、调用追踪后返回对比分析，当前会话中的设置与临时范围仍保留。

## 侧栏、列表反馈与模态层

设置侧栏与图表区用灰色细 divider 分隔。右侧视图标题前的无边框 chevron 控制侧栏展开／收起，使用与调用记录相同的 340ms 缓出动画，宽度与图标同步过渡；两方向均可中途反向操作。内层保持 300px 固定宽度，外侧占位含分隔留白，收起后释放宽度与间距给图表；不挤压列表文字重新排版。收起立即设为 inert／aria-hidden，展开恢复，选择、设置草稿及数据范围不丢失。减少动态效果设置下即时切换。

共享 List 的 surface 模式由整个 ListItem 绘制 hover、选中和键盘焦点反馈；文字区与删除操作区均处于同一高亮表面。删除按钮仍是列表项内部的独立操作，不触发行激活，不在行外悬挂独立背景块。

编辑、数据范围、数据列和帮助模态窗口均使用 native showModal、明确的 fixed/inset:0/margin:auto 居中规则，以及覆盖整视口的半透明黑色遮罩和轻微背景模糊。尺寸受视口约束，长内容内部滚动；Escape／关闭恢复焦点，遮罩后的页面不可交互。不能依赖已被样式重置的浏览器默认 margin 实现居中。


## 新建与编辑：三列模态窗口

编辑使用独立草稿，保存后更新并激活；取消、关闭或 Escape 丢弃草稿，新建取消不产生列表项。

| 列 | 内容与行为 |
|---|---|
| 左列 | 设置名称、图表列表、添加入口；列表可激活图表、拖拽排序，落点显示细线；Alt + 上／下箭头提供键盘排序。标题右侧为带 tooltip 的 plus IconButton，每项右侧有删除图标。 |
| 中列 | 当前图表设置，固定顺序为自定义标题 → 添加数据列 → 图表类型 → 按类型配置轴与分组映射。 |
| 右列 | 整套草稿的实时图表预览，使用主视图的同一渲染组件及布局。 |

三列之间使用全高灰色细 divider，位于列间留白中央；标题右侧 plus 按钮保留“添加图表”tooltip 和无障碍名称。三列分别滚动，列宽在窄视口依组件配方收窄；右侧预览按自身可用宽度使用同一套图表断点。

新图表追加末尾。删除当前图表后选原位置下一项，没有下一项时选上一项；删除其他图表不改变选中项。删空后中列显示“选择或添加图表”，添加入口仍可用。所有这些操作属于草稿，取消恢复已保存视图。

图表列表拖拽只调整顺序，不是画布上的自由拖拽定位。页面不提供 Dashboard 的多套 layout 切换或逐图尺寸配置。

无可用数据时编辑预览使用明确标识的合成演示数据；新图表尚无数据列时使用仅供预览的占位列，不写入草稿或导出。主视图无数据时显示空态，不用演示数据伪装真实结果。

## 数据列与图形映射

数据列引用已有指标并保留独立身份，名称与单位只读；支持多种聚合的指标在轴映射中选择口径。同一指标可以定义多列，如延时 P50、P95。选中数据列区域不再放名称编辑输入框，也不为只有一种口径的指标放无效下拉菜单。数值映射从已选数据列中勾选参与绘图的子集；多个聚合口径在对应数值映射项下选择。数据列经过图形映射才产生 series，二者不直接等同。目录支持检索与分类；图表只允许加入可在同一张图中表达的列。

一张 Card 只对应一张图。兼容列成为同一绘图区中的系列，不在一个 Card 内堆叠多张独立图；不提供结果表格或图表／表格切换。

| 类型 | 映射 |
|---|---|
| 柱状图、折线图 | 横轴为分类字段；“系列分组”为分组字段或“仅按指标”。最终系列为数据列 × 分组值，不把两种字段拼接为长横轴标签。 |
| 条形图 | 纵轴为分类字段，横轴为数值；系列规则同上。 |
| 面积图 | 当前按日期排序，非堆叠；分组值生成多系列，不将分位数或比率相加。 |
| 热力图 | 列与行各映射一个不同字段，颜色为数据列计算值。单指标也能形成行 × 列矩阵；颜色映射从已选数据列中单选。缺失组合保留空值，不补零。 |
| 雷达图 | 数据列为辐射轴，“比较对象”字段提供分组；至少三列才绘制多边形。量程使用原单位，不暗示向外更优。 |

切换类型保留数据列并更换映射控件。面积图选择日期；热力图缺少行字段时初始化一个不同于列的字段，用户可以调整；雷达图忽略分类图的辅助分组，切回时保留原配置。少于三个雷达轴、空数据列、空数据范围应显示具体提示。

添加、改变口径、导入均检查兼容性。当前数据都为调用事实粒度，按图表统一分组，另要求结果单位及分母一致：USD、USD/Delivery、USD/调用不可共用数值轴；不兼容选项禁用并提示新建图表。生产能力目录还需声明粒度、合法维度、单位、聚合方式和缺失处理，不能仅靠单位字符串判断。

当前为同单位单数值轴。未来启用双 Y 轴时必须左右分别显示轴名称、单位和刻度，系列明确绑定其轴；跨单位雷达归一化未定义前不开放。

## 排列与表面

卡片宽度随右侧 view 可用宽度响应，最小 480px、最大 640px。断点以容器宽度 W 为准：md 及以下（W < 1044px）一列，lg（1044–1565px）两列，xl（1566–2079px）三列，2xl（W ≥ 2080px）四列。列数不随图表数量改变，不足一行按顺序占位，包含空列的整组列居中。侧栏展开／收起及编辑预览都按实际容器宽度切换档位。间隙 g = max(16px, min(32px, W × 2%, (W − n × 480px) / (n + 2)))；列宽 c = clamp(480px, (W − (n + 2)g) / n, 640px)。左右边距为 (W − nc − (n − 1)g) / 2，正常宽度下至少为间隙的 1.5 倍；列内间隙向上取整至像素。容器不足 480px 时单列保持 480px，在图表区内横向滚动。按列表顺序从左向右分配列，每列独立向下堆叠，避免同行高差形成空隙；不回填最短列。DOM、保存顺序仍是列表顺序。调整容器宽度只重新分列，添加仍追加列表末尾。

图表遵循 [D17 公共卡片表面](../foundations/card-surfaces.md)：较亮 Card 灰底、12px 圆角、1px 约 6% 白色细边框及双层淡阴影。承载区域和编辑器使用更深的 workspace 层级，不能与图表同色。复用共享表面，不叠加私有图表阴影。

卡片 Header 左侧仅为自定义标题，右侧是共享图例，使用指标名称及必要的聚合口径；热力图放色带和范围。移除横轴／分系列配置摘要及 Delivery 数。字段或指标名称、单位在坐标轴处标注，条形图交换轴方向，热力图在行侧和列上方标注，雷达图标注辐射轴与原单位量程。

刻度、范围、单元格及提示最多显示两位小数，原始计算保留精度。窄卡片按绘图区宽度降低刻度标签密度，保留首尾，完整值保留在数据点提示中。

## 全局范围内选择 Delivery

页面将 Header 的起止时间与范围文案传入组件。对比分析不额外提供 Header Task 范围；通过数据范围模态窗口完成进一步检索、过滤和选择，不能超出全局边界。

入口默认“数据范围”，缩小后显示“已选 N 个”。模态窗口提供字段检索、可展开筛选、多选列表、命中数和选中数；恢复全局范围解除局部限制。检索复用 SearchField 的 prefix slot 与正式字段规则：ID 精确，名称关键字，Workflow 无 @ 按名称、含 @ 按唯一 selector 匹配。

选择全部命中覆盖完整查询结果，不仅是可视行；不在当前命中中的已选项保留。应用才更新图表，关闭或 Escape 放弃选择草稿。全局范围改变后，实际参与数据为本次选择与全局集合的交集；零交集明确为空，不能偷偷恢复全选。设置切换、删除和导入不改变本次范围。

## 导入、导出与数据边界

导出 JSON 为 `kind: crystra-observation-setting`、`version: 1`，包含激活设置名称、图表顺序和各图表配置，不含未保存草稿、临时 Delivery 集合或全局范围。导入验证版本、结构、指标、口径、映射、类型及重复身份；错误保留现有设置，有效文件作为新设置加入，同名不覆盖。旧文件的 view 和 width 字段忽略，新导出不再包含它们；类型缺省兼容为柱状图。

数值映射保存为可选 `valueItemIds`；省略表示全部数据列，空数组表示未选择数值项。引用必须存在于图表数据列中；切换图形类型当前重置数值映射，热力图选首项，其他图形恢复全部。

2026-09-11 用户裁定（D23）：观察设置与总览统一 [配置文件交互](configuration-files.md)。导出直接下载 JSON，导入使用系统文件选择器；共享 `downloadConfiguration` 与 `ConfigurationFileInput`，文件内容和校验仍由调用者负责。选择取消不改变配置，校验成功才新增设置并激活；同一文件可再次选择。

本地样本含 48 个合成 Delivery、每个 12 条调用，固定全局 7 天内命中 42 个。指标目录提供 9 项：实际费用、输入 Token 缓存命中率、API 调用次数、首次输出延时、输入 Token 数、输出 Token 数、缓存命中 Token 数、未命中缓存 Token 数、总 Token 数。费用支持总量／每 Delivery 平均／每调用平均，延时支持均值／P50／P95，其他指标使用已有固定口径。目录支持搜索和资源／费用、延时分类；9 项是可由当前合成事实计算的示例，不是生产指标上限。缓存率按原始 Token 汇总，分位数样本使用 nearest-rank。日期分组当前以 Delivery 开始日期（UTC）演示；生产需统一全局时区及分桶契约。

HTML 不能替代以下生产能力：索引与游标查询、跨游标全选、权限过滤、指标 owner 计算与缺失状态、设置持久化和并发版本冲突、数据更新后的身份失效处理、完整 i18n key。需区分 unavailable、not-applicable、coverage 与 lower-bound；前端不得把缺失补零，或从差异生成因果、质量评分和 winner。以上边界由系统契约及对应 owner 补齐。
