# 工作流工作台

更新：2026-09-13。当前 UI/UX 需求与接入边界见[业务接入需求](workflow-studio-contracts.md)，资源展示见[资源配置](workflow-resources.md)。[v8](../assets/crystra-workflow-studio-v8.html)为交互样本；活动图全部几何与路由规则以[布局优先候选](../components/workflow-map-layout-candidate.md)为准，不把早期实验并列生效。

## Workspace 与统一投影（2026-09-12）

工作台 Agent 的 workspace 是当前某一个 workflow 的可编辑包目录，包含其定义及关联资源。例如开发仓库中的 `workflow-package/implementation/`；不是整个 `workflow-package/` 集合，更不是该 workflow 将来执行任务时所操作的业务项目目录。实际宿主路径由具体工作流上下文解析，不硬编码仓库路径。

三个工作面均是该 workspace 的投影，而不是各自维护独立的一套业务数据：

| 工作面 | 投影与编辑对象 |
| --- | --- |
| 流程设计 | 流程定义、层级、控制与数据关系，以及节点对执行配置的绑定 |
| 资源配置 | 当前 workflow 包对用户暴露的语义资源、内容与关联图 |
| 结晶分析 | 当前流程与资源中的可优化部分，以及候选变更和验证材料；关联运行证据作为有明确来源的分析输入 |

左侧对话持续操作同一 workspace；切换右侧工作面改变的是观察/编辑角度，不切换 Agent 的工作目录或复制工作流。Agent 修改文件与用户直接编辑界面，应经同一变更与校验通路写回 workspace，并刷新所有受影响投影。界面候选需携带基线，外部文件变化时重新解析、报告冲突，不能用旧页面状态覆盖新文件。解析失败时保留最后有效展示并呈现问题，不把未解析内容当成已生效。

文档、校验器、结构约束、适配依赖等由 Agent 在该工作流边界内维护，普通界面不暴露全部底层细节。引用的外部共享资源不因被引用就成为该 workspace 的写入对象；需要改动时另行遵循资源归属与版本规则。结晶分析可读取明确选定的外部运行证据，但不会因此把业务项目目录作为默认 workspace。

Workspace 是可编辑草稿，不代表已发布版本。既有版本发布门禁继续生效；已发布包/缓存不得被界面草稿原地改写。具体文件写入、监听、事务/冲突处理、Agent 接入和正式发布目前仍未实现。本轮 HTML 使用样本与页面会话状态展示投影交互，不能宣称已在真实 workspace 上读写。

## 身份与 Header

工作台针对一个具体 workflow。Header title 显示解析后的 workflow 名称，subtitle 显示该 workflow 的描述；两者在三个工作面切换时保持一致，不使用固定页面名称或页面用途说明。无参数样本为 Implementation；`workflow_definition_id=build-and-sign&revision=v3` 显示 build-and-sign；未知身份保留请求名称并显示未解析状态，不能替换成其他工作流。只有 revision 而没有 workflow 时显示「未指定工作流」。`new_workflow=1` 为「新建工作流」空态，不实际创建资源。

Header 与分析页复用 `page-header.css`：左侧身份，紧随其后的透明 underline Tabs 贴底排列，右侧版本上下文。Tabs 为流程设计（`view=studio`）、资源配置（`view=resources`）、结晶分析（`view=crystallization`），切换保留 workflow / revision 及其他来源参数。旧 versions / runs 或未知 view 回到流程设计。版本与关联运行是上下文和证据入口，不再占据一级页签。

## 流程设计

目的：确认当前流程和资源绑定，增删节点、调整关系与条件，更新 skill、template、script 等配置。查看与编辑位于同一工作面；区分当前配置、候选差异和已应用状态，不分成独立查看页与编辑页。

左侧复用 DSH Input；右侧以活动图为主，节点、连线选择打开详情。叶子活动详情展示并允许直接选择、替换和解除资源绑定；资源管理与内容编辑在资源配置页完成。Role/script 互斥、Skill 独立绑定和 Template 适用性见业务接入需求。缩放、适应视图、布局方向和阶段导航仅改变视图。选择对象后「在 Chat 中调整」把对象身份及修改意图加入输入草稿，由用户继续描述、发送，不自动提交。

候选修改应叠加到活动图，说明新增、删除、变更与资源替换；应用前需检查候选基线与校验反馈。当前 HTML 演示对象引用和候选提示，尚未连接 LLM 生成、语义 patch 校验、版本保存或发布。不得以样本替代真实写入协议。Input 在三个工作面切换时保持同一实例，未发送草稿不得丢失。

## 结晶分析

2026-09-13 用户确认定稿（UI/UX）：左侧 Chat 表达意图、讨论拆分与推荐，右侧围绕一项候选展示活动变化与收益。目的不是指标报表，也不是一次性把所有 Role 替换成 Script；优先拆出确定性提取、校验和排版，保留 Agent 判断与恢复路径。

当前 v8 展示“报告处理”局部方案：原 Agent 整体读取/判断，拆为 Script 提取校验 → 格式判断 → Agent 异常判断 → Template 输出；不支持的格式通过 Agent 补齐后继续。此图为设计样本，不伪称从当前工作流或 Delivery 自动分析生成。

| 区域 | 交互与含义 |
| --- | --- |
| 方案 Header | 名称、候选状态、检查与应用入口；应用前验证基线、资源与接口 |
| 变更前/后 | 复用 component-preview 的 ToggleSwitch（round、choice），两侧文字标明变更前后，使用组件原有滑块动画与主题；不使用分段按钮或独立外观；默认变更后；按同一局部活动范围切换，不并排挤占空间 |
| 活动图 | 成熟 ELK 正交布局；新增、调整、保留有图例；点击或键盘选择打开右侧悬浮变化详情 |
| 变化详情 | 拆分职责、输入输出、保留判断与失败去向；“在 Chat 中讨论”仅加入草稿 |
| 收益与验证 | 可收起的历史依据、收益预测、实测对比三栏；历史占用依据、预测与版本实测分开呈现 |
| 检查方案 | 居中遮罩模式框列出脚本、接口、样本验证缺口；应用禁用时说明原因 |

预期收益、历史回放和真实运行收益是三种证据状态。生产应展示来源、样本数量与范围、适用条件、新增执行成本和质量退化，不把脚本成功等同业务收益。无数据不显示精确百分比。解释主要留在 Chat 或详情/help 中。

正式应用只写可编辑草稿，随后流程设计和资源配置同步刷新；发布仍经过版本门禁。候选需绑定精确 workflow/revision、活动及资源身份，并保持差异来源；陈旧基线拒绝应用。当前尚未接入生成、回放或写回，应用按钮明确禁用，不产生伪成功。

样本复用 Button、Card、Chip、IconButton、Typography、WidgetTooltip；变更前后数据由纯语义 fixture 生成，布局调用流程设计候选的 `buildBranchBlocks` 分层构件与 `chooseRoutes` 端口/路线选择，禁止回退旧 `layoutWorkflowMap`。生成器 `assets/build-crystallization-layout.cjs` 输出带语义匹配检查的布局资产，修改 IR 后必须重新生成。主工作流56状态保持原资产。本局部示意尚未提供完整流程下钻与手势相机，不代表这些能力已完成。

本轮增加通用“补救后前向汇合”条件：同层判断的保障分支进入一个单入口/单出口辅助活动，该活动以 advance 汇合到判断的直接 expected 后继时，辅助活动沿侧轴布局，不让它占据主干。不把 advance 改为 return，不按业务名称/ID 指定坐标；详情见完整布局规则。

实现：`components/workflow-crystallization.tsx`、`workflow-crystallization.css`；[浏览器验收](../assets/workflow-crystallization.test.mjs)覆盖前后切换、活动详情、Chat引用、阻塞应用和模式框。右侧保持同一共享 Chat 实例；首次进入追加明确标记的样本推荐，正式自然语言答复未接入。

## 动作与状态

| 区域／动作 | 效果与边界 |
|---|---|
| Header 页签 | 切换流程设计／资源配置／结晶分析，保留 workflow 身份和 Chat 草稿 |
| 活动图节点／连线 | 打开对象详情，不直接改语义 |
| 绑定资源 | 在活动详情直接修改绑定，与 Chat 共用校验/提交通路；正式绑定接入尚未完成 |
| 活动图阶段页签／关系角标 | 按层级展开/收起与大纲导航，保留原关系和边界接口；不是多份 workflow |
| 结晶收益 | 展示待验证假设；正式证据检索与回放未接入 |
| 结晶变化节点 | 打开该拆分项的浮动详情与输入输出 |
| 在 Chat 中调整／研究 | 写入输入草稿并聚焦，用户发送前无业务写入 |
| 应用到草稿 | 当前样本因验证缺失禁用；正式应用后同步两个投影，不自动发布 |
| 未解析／新建／无证据 | 保持请求身份与空态，不加载替代工作流或伪造证据 |

## 流程设计交互索引

| 入口 | 行为 |
| --- | --- |
| 单击节点 / Enter / Space | 选择、突出结构可达上游、打开详情并定位镜头；不修改定义 |
| 复合活动 chevron | 展开子层并居中取景；保留跨层输入输出、来源去向；收起回父层 |
| 大纲 / 搜索 / 面包屑 | 大纲仅复合活动；搜索深层对象展开祖先；同级切换以新对象为焦点 |
| 返回焦点 / 适应当前层 / 全图概览 | 三个不同取景语义；手动平移后仍能找回焦点 |
| 缩略图 | 全局定位与视窗移动，不改语义或当前工作流 |
| 预期路径 / 全部路径 | 切换结构突出范围，保障路径减淡不删除；不冒充运行事实 |
| 横向 / 纵向 | 布局与接口政策转置；底部方向、路径菜单向上展开 |
| 绑定详情 | 直接选择、替换、解除活动绑定；变更进入草稿校验而非立即发布 |
| 保存草稿 / 发布版本 | 草稿保留待完善诊断；发布对准确版本重新校验，阻塞项禁止发布 |
| 帮助 / 设计验证台 | 居中遮罩模式框；样本 JSON 输入是评审能力，不要求普通用户手写 IR |

工具放 Header 右侧，共享 icon button、tooltip 和无障碍名称。动画尊重减少动态效果设置。节点形状、关系颜色、接口、取景和路线的完整约束见[布局优先候选](../components/workflow-map-layout-candidate.md)，不在页面重新维护另一套参数。

## 共享左右栏

三个工作面共用左侧 Chat 与右侧展示，拖动 divider 调整宽度。Chat 最小360px、最大为工作区可用宽度的一半；键盘方向键每次16px，Home/End到边界。低于720px保留最小工作宽度，不以违反最小宽度实现挤压。切页保留对话、草稿与栏宽。

## 当前接入依据

活动图以 `workflow-map-workbench.tsx`、`workflow-map-ir.ts` 和候选布局资产为现行原型，旧 `workflow-activity-study` 多 Tab 实现仅作历史证据。当前交互与业务待办按[需求验收表](workflow-studio-contracts.md#需求验收与接入缺口)检查，旧两页测试不能代替三个工作面及资源管理的验收。


### 结晶收益呈现修订

结晶服务长期重复使用的工作流：Agent 消费历史观测发现可固化部分，提出拆分/替代，形成新版本，再利用现有 Evaluation/分析指标比较。无需结晶收益分。费用、Token和延迟优先使用实测；预测独立展示，不写入实测 metric 或由前端另造正式口径。

历史依据展示拟替代活动的实际费用占用、关键路径耗时及样本；不以活动数量占比估算。预测需考虑适用比例、保留 Agent 判断、新增脚本开销及恢复频率，记录算法版本、输入与假设，后续可逐步改进并核对预测偏差。端到端耗时不能由并行活动时间简单相加。没有候选运行数据时，实测对比显示空态，不能借用预测填补。

当前 v8 三栏中的120个 Delivery、38%/24%占用及18–26%/8–14%预测区间都是明确标记的静态设计 fixture，仅用于审阅视觉；没有从真实 Evaluation 取数或执行预测算法。预测详情通过共享模式框解释，历史依据入口仅加入 Chat 草稿。正式数据需展示精确版本、样本、覆盖率、口径与来源；候选版本运行后采用服务提供的可比指标和差值，不由 UI 推断收益事实。

用户已确认本轮历史依据／收益预测／实测对比设计；预测算法与真实取数仍是后续接入能力。


### 结晶分析定稿基线（2026-09-13）

用户裁定：“可以，结晶分析按照当前的设计定稿。”本次认可的是当前 v8 的结晶分析 UI/UX，不是执行协议、预测算法或生产功能发布。

定稿范围：共享左侧 Chat；右侧活动调整与拆分预览；复用组件样本的圆角 ToggleSwitch 切换前后；活动变化浮窗与 Chat 引用；历史依据、收益预测、实测对比三栏；方案检查及受校验约束的草稿应用。布局复用流程设计的分层拼装与路线选择，包含补救后前向汇合的通用规则，不允许回退旧适配器或按业务节点指定坐标。

后续业务实现以本页及[业务接入需求](workflow-studio-contracts.md)为输入，保持演示的视觉与交互。真实观测/Evaluation取数、预测算法与版本、Agent候选生成、精确资源绑定、应用写回和发布接入仍待实现；不能将样本数值或“候选方案”的业务状态改写为已验证事实。页面里的候选标记表示待应用的工作流调整，不表示本页 UI 仍待设计确认。
