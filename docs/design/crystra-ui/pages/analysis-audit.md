> 当前稿：[Analysis v8](../assets/crystra-analysis-audit-v8.html)，2026-09-11。已确认方向为“总览 / 调用追踪 / 对比分析”，默认总览；对比分析设计已按 D22 确认并接入，真实服务尚未接入。Workflow Studio 实验不在本次范围。

## 三个工作面的职责

| 工作面 | 要回答的问题 | 当前页面组织 |
|---|---|---|
| 总览 `view=dashboard` | 整个系统运行状态如何，哪里需要关注？ | Dashboard Widget 网格 |
| 调用追踪 `view=traces` | 一个 Delivery 的实际调用路径是什么？ | 可收起、搜索筛选的 Task / Delivery 侧栏目录，主区 Trace 瀑布图 / 树图与 Span 详情 |
| 对比分析 `view=reports` | 不同版本、角色与时间范围下，表现有什么差异？ | 左侧观察设置列表，右侧所选设置的图表；三列模态窗口编辑设置 |

审计作为来源下钻能力，不单独占第四个工作面；调用追踪不再保留页面级“来源与记录”按钮，其他工作面的来源入口按各页规则维护。三个工作面复用页面 Shell 和 Header 的范围选择，采用各自适合的内容布局，不再把所有页面固定为旧运行目录 / Trace / 证据三栏。

## Header、范围与导航

Header 由页面注入 identity、navigation、time 和 context 槽位。身份区仅为 title「观测与分析」与 subtitle 两行；underline Tabs 位于标题区右侧，tab 与下划线一起贴住 Header 底边，不在 subtitle 下增加第三行。导航采用 16px 字号、24px 行高和 52px Tab 高度，下侧留白 16px，使文字与下划线之间更舒展。右侧第一行为日期范围、立即刷新和更新周期，第二行右对齐放置总览的「编辑布局」，编辑中向左展开为图标按钮组「导出布局 / 导入布局 / 添加 Widget / 保存 / 取消」，文字说明由 Tooltip 提供；调用追踪显示范围上下文，对比分析不重复设置页内范围；移除 Header 的「示例数据 · 读取于」提示；本轮 Header 高约 89px，不据此冻结其他页面的 Header。更新周期的 label 与选中值共用垂直中心和行高，控件高度与邻近按钮一致。

日历按钮从下方展开双月选择面板，支持月份切换、点击起止日和直接输入起止时间，精确到秒；「最近 7 天 / 最近 30 天」快捷按钮位于弹窗内的日历下方，不独立占 Header。示例明确使用 UTC+08:00。点击日期默认覆盖完整起止日，秒级输入可以进一步收窄。编辑先保留草稿，「应用」后才更新范围；取消、外点和 Escape 不提交。起止顺序错误、不完整或超过一年时禁用应用并说明原因；最大跨度为一个日历年，限制集中配置，后续可依据实际性能测试调整。快捷按钮立即生效。各工作面继承全局时间范围；观察设置文件不保存时间范围。

总览没有「观察范围」控件，时间范围作用于整个系统；从其他页返回总览时，不继承 Task 筛选。调用追踪保留 Task 范围上下文；对比分析通过数据范围模态窗口在全局时间范围内选择 Delivery，不额外显示 Header Task 选择器。

更新周期默认手动，可选 15 秒 / 30 秒 / 1 分钟 / 5 分钟；立即刷新不改变范围、工作面和观察设置。当前刷新只重新读取本地示例，不伪造新调用或实时服务反馈。示例时间锚点为 2026-09-09，覆盖 08/11 — 09/09；区间外显示空态。当前统计 fixture 是按日汇总的样例，按日桶与范围相交展示，不宣称具有秒级统计采样；Trace 使用真实样例时间戳按秒筛选，09/09 的 v2 / v3 分别发生于 UTC+08:00 的 18:32:00 / 22:08:00。

`view`、`period` 写入 URL；仅调用追踪写入 `scope`。period 为 `7d` / `30d` 或 `custom:YYYY-MM-DDTHH:mm:ss/YYYY-MM-DDTHH:mm:ss`（UTC+08:00），兼容旧日期区间和 `3d` 链接。`scope=demo-*` 仅为本地示例范围，不代替真实 `task_id`。Header 和 Sidebar 在页内切换工作面，保留观察设置、临时数据集和总览布局。旧 `analysis` / `audit` 入口映射到调用追踪，旧 `compare` 映射到对比分析。

当前对比分析不提供从图表直接打开 Trace 的入口；通过 Header 切换调用追踪保留全局时间，不从图表暗中推导 Task 或版本。真实 `task_id`、Delivery、Run、Trace、Span 或 Gate 来源参数进入时保持原身份，显示未解析状态，不回退成本地例子。返回 Gate 继续携带来源参数；生产草稿与视口恢复归宿主。

## 总览

总览围绕两个主题组织，复用 `DashboardGrid` 和 `SemanticWidget`，各主题独立布置网格，共用 Header 的时间范围与布局编辑器。这轮主题与指标方向已确认，具体页面样稿待用户审阅。

| 主题 | 周期汇总 / 展示 | 趋势与分组 |
|---|---|---|
| 资源消耗 | 按量实际费用、订阅用量等价估值、API 请求总数、Tokens 总量；三个 Provider 的缓存命中率小表盘；订阅费与订阅周期 | 每日费用堆叠柱、请求多序列折线、Tokens 堆叠柱；Provider / Model 分组切换，Token 趋势支持合计 / 输入 / 输出 |
| Workflow 运行质量 | Role 平均执行时间、同 Role 的各模型单位执行费用及样本量、Role × Model 返工发生率 | 每日最长无人工介入运行时间、每日人工介入及原因分布；按 Workflow、Role 筛选 |

需求先于当前采集能力：上述金额估值、缓存、Role 执行与自主运行需求均保留，后续由对应服务补齐口径和适配，不用现有 Evaluation metric 集合裁剪需求。现有候选仍是参考指标池，不因页面示意而重写生产 Catalog。

费用分别表达实际按量费用与订阅用量的按量等价估值；每日堆叠明确包含订阅估值，旁边注明订阅费与订阅覆盖日期，让用户判断订阅使用价值，不自动给出盈亏结论。当前 Copilot ¥160/月及所有用量、价格系数均是虚构的设计样本，不代表实际套餐价格。样例周期为 08/11—09/09，订阅示意周期为 09/01—09/30。

同 Role 的模型费用用每次 Role 执行平均费用比较，每格同时提供执行样本数；返工表示出现返工的 Role 执行占比。人工介入按计划内裁决、纠偏、主动变更展示，无人工介入时间表达每日最长连续运行区间。当前曲线均为设计 fixture，正式算法和真实数据源仍待对接。

四张用量汇总（按量实际费用、订阅用量等价估值、API 请求总数、Tokens 总量）使用 1×2 数字 Widget，外部尺寸 336×160px，直接展示标题、数值与单位。默认布局按用量汇总、每日趋势、缓存与订阅信息分行。

Provider 在费用、请求、Token 与缓存表盘间保持颜色一致；Model 保留 Provider 前缀和来源配色关系。1×1 继续使用既定居中图标 / 表盘与 Tooltip，不另造样式。

Widget 继承既有数据形状 → 可选表达 → 容量约束的关系，网格采用 160px 单元及 16px 间隔。紧凑 Widget 仍使用声明的离散尺寸；图表的预设尺寸是快捷项，并允许输入自定义整数行列，只检查表达规定的最小尺寸，不设组件级上限。超过当前可见列数的图表保留单元大小，由本主题网格局部滚动。编辑布局时可拖动；右键菜单提供同义表达、预设 / 自定义尺寸，并对适用图表提供数值范围设置。保留现有吸附 ghost 与动画。保存 / 取消布局作用于本页会话。只有保存或取消退出编辑，按钮组随后向右折叠回「编辑布局」。展开与折叠共用同一个外框，固定右边缘，以约 560ms 的两段动画先完整收拢到 34px，再扩张到目标宽度（图标组 184px / 编辑入口 104px）。旧内容在收拢阶段淡出，新内容只在第二段扩张时渐显，不重建或突然出现另一个按钮。快速反向操作从当前实际宽度衔接。遵循系统减少动态效果设置；切换工作面、文件操作、添加 Widget、点击空白及 Escape 不退出编辑。取消恢复进入编辑时的完整网格，包括本次新增和导入的变更。

总览内容区直接展示 Widget 网格，不再显示「运行概况 / 查看来源」工具行、「需要关注」卡片和「研究与报表」卡片。对比分析与调用追踪通过 Header 导航进入。对比分析不提供固定到总览的入口，两者分别维护观察设置和 Dashboard 布局。

### 布局文件与添加 Widget

2026-09-11 用户裁定（D23）：导出直接下载当前编辑中的布局 JSON，不打开另存为窗口；导入调用系统文件选择能力打开 JSON，完整校验后替换当前布局草稿，可继续调整再保存。取消文件选择不改变草稿；格式、数据源、表达方式或尺寸不匹配时提示失败并保留原布局。文件读取期间避免重复操作，结束后继续编辑。与观察设置复用 [统一配置文件交互](../components/configuration-files.md)，不再依赖 showSaveFilePicker／showOpenFilePicker。浏览器自身的下载位置偏好由浏览器负责。

当前原型文件格式为 `format: crystra-observation-layout`、`version: 2`、`name` 和 `widgets`。每个 Widget 保存 `id`、`title`、`view`、`grid: {x,y,w,h}`，以及数据绑定：新建项使用结构化 `query: {metric, providers, models, groupBy, time, tokens}`；原有默认示例仍使用 `source`。图表另保存 `range`，记录自动、从零、完整百分比或自定义上下限策略。`providers` / `models` 为 `all` 或指定身份数组，Model 身份包含 Provider。导出配置而非指标值快照；导入兼容旧版 1 的示例来源绑定。该格式用于当前观测页原型，不替代生产指标或 Layout 公共契约。

「添加 Widget」打开带实时预览的模态窗口，按三个配置区组织（当前交互样稿待审阅）：

1. **观察指标**：选择费用、请求次数、Tokens、缓存命中率或运行质量指标；不再把每个 Provider 的示例卡片作为独立指标选项。
2. **范围与数据组织**：选择全部或指定 Provider / Model，选择合并统计或按 Provider / Model / Role 分组，以及周期汇总或按日趋势。选项由指标声明提供，Tokens 另有合计 / 输入 / 输出。Provider / Model 来自当前记录的维度集合；新增来源不会增加一种指标。`all` 动态包含新来源，指定集合保持原身份。
3. **表达、尺寸与数值范围**：查询结果转换为既定数据形状，再由 `familyViews` 提供兼容表达、预设尺寸和最小容量。图表可输入无组件级上限的自定义行列；折线、柱状图与热力图可选自动适配数据、从零开始、完整百分比或自定义上下限。标题可自定义。左右配置与预览同步，不另造 Widget 绘制分支。

缓存命中率支持多 Provider / Model 在一张分组条形图、柱状图或数值表中比较；按日趋势可用多序列折线。自动范围依据当前数据突出差异，完整百分比范围固定为 0—100%，也可自定义。合并统计按累计命中输入 Token / 累计输入 Token 计算，不平均来源百分比，也不堆叠百分比。无匹配数据时显示暂无数据，缺失比率保留为空。热力图同样默认按数据自动计算色标范围，并在图例中显示真实上下限。

新查询继承 Header 时间范围；运行质量继承页面 Workflow / Role 筛选。新建项的 Provider / Model、Token 类型和分组配置属于自己的查询，不跟随默认示例卡片的分组按钮改写。订阅信息、无人工介入运行时间和人工介入目前复用对应 fixture，配置项按其已提供能力展示；全部结果仍为本地设计样本。

确认后生成独立实例，追加到指标所属主题网格的最后一行之后，用户自行拖拽定位；关闭 / 取消弹窗仅放弃这次添加。查询由宿主数据适配层计算，Widget 继续按数据形状、表达和尺寸渲染；保存 / 取消、导出 / 导入包含新查询配置。

实现：[布局编辑器](../../../../wsr-ui/packages/bi/src/components/observation-layout-editor.tsx)。示意：[编辑按钮组](../assets/analysis-layout-edit-v8.png)、[添加 Widget](../assets/analysis-widget-add-v8.png)、[自定义尺寸与数值范围](../assets/analysis-widget-chart-options-v8.png)。

## 对比分析（D22 已确认）

用户选择观察设置，在全局时间范围内进一步限定 Delivery 数据集，比较费用、缓存、调用和延时等差异，不生成 Workflow 结晶方案。完整布局、映射、样本能力与生产边界以 [观察设置组件契约](../components/result-analysis-review.md)为准，本节取代旧研究表单、Delivery 横轴明细与固定到总览流程。

左侧为可折叠观察设置列表，以灰色 divider 与图表区分隔，展开／收起及 chevron 均有 340ms 过渡；列表整行含编辑／删除操作共享 hover／选中高亮。标题区仅提供修改／导出／导入／新建；每项均有编辑与删除入口，编辑位于删除左侧。右侧 Header 仅保留当前设置标题与数据范围入口。切换设置及返回其他工作面保留本次范围。

新建和修改打开带全屏遮罩、居中的三列模态窗口：图表列表（拖拽排序、逐项删除）→ 当前图表设置（数据列、类型、对应映射）→ 实时预览。独立草稿保存后应用，取消不影响当前视图。

一张 Card 一张图，兼容数据列形成同图系列，不显示结果表格。支持柱状图、条形图、折线图、非堆叠面积图、真实行列热力矩阵和雷达图。图例位于标题右上，坐标轴标注名称与单位，数值最多两位小数。卡片在 480–640px 内随右侧可用宽度响应，以 1044／1566／2080px 为断点分为 1／2／3／4 列并在列内独立堆叠，列数不随图表数量变化；包含空列的整组列居中，间隙自动调整为 16–32px，两侧自动留白通常大于间隙；使用 D17 灰度层级、弱边框及淡阴影。

观察设置导入／导出仅包含设置与图表配置，不包含临时数据范围；删除设置不删除可观测数据。索引查询、聚合 owner、权限、游标、缺失状态及持久化仍需生产接口，HTML 只演示已确认的视觉与交互。

## 系统读取边界

Evidence Query 是事实与 Trace 读取边界；Metric Result / Delta 从指标 owner 获取。设计 fixture 的前端聚合不授权生产 UI 自行实现指标、创造收益、winner 或因果判断。当前系统契约与本页未来研究维度的查询适配仍需对接，不因 UI 支持筛选而宣称生产接口已存在。

缺失不等于零；保留 owner 的 lower-bound、unavailable、not-applicable、coverage 与兼容性。Compare 单侧失败保留成功侧和原因；无基线不推断快慢。链接恢复范围，不承诺数据永久不变。Trace 播放只重放记录，不模拟新的执行；精确定位使用 `(trace_id, span_id)`。

分析中的查询、布局与观察设置配置是视图操作；禁止删除审计、修改 evidence/verdict 或直接重跑 Workflow。需要纠偏时回到 Task / Chat 表达新意图。

## 2026-09-11 归并：对比分析的当前设计

以下是 [观察设置组件契约](../components/result-analysis-review.md) 在本页的组合，不另建页面私有组件：

- 观察设置侧栏有 divider，可按 340ms 动画收起；每项整行 hover／选中，右侧编辑 icon 在 trash 左侧。
- 右侧只有设置标题、数据范围和按顺序排列的图表 Card；可用宽度 <1044、1044–1565、1566–2079、≥2080px 分别为 1／2／3／4 列，列数不依赖图表数量；每列 480–640px，整组居中、边距通常大于间隙。
- 编辑是居中、带遮罩的草稿模态：图表列表／图表设置／整套预览三列，以细 divider 分隔；添加图表使用 plus IconButton。
- 数据列只引用已有指标，名称与单位不可改；目录可检索及分类。先选数据列，再选图形类型，再配置轴与分组，聚合只在指标支持多种口径时显示。样本的 9 项指标不限制生产目录。
- 数据集在 Header 全局范围内进一步缩小；与设置独立，切换设置或工作面不重置。
- 所有已确认视觉规则仍遵守 D17；本次归档不等于主题变量或生产服务已接齐，见 [逐页审核](../handoff/v8-design-audit.md)。
