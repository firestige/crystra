Card 模块化，Widget 内容语义化

Root：尺寸、边框、背景与状态。

Header：可选 leading 图标、title/subtitle、trailing 状态或工具。

Content：primary + 可选 visualization + supporting。

Footer：可选 provenance / freshness 与 actions。

空模块不占位；点击内容区与补充操作分离。图表模块只有需要时才存在。

组成与分布

总量由什么构成？

2×2 一个总量、最多三个相关组成；复杂分类、直方图、热力图用大面板。

尺寸：2×2 简要拆分；2×3、3×3 分析图

记录明细

哪些记录支持这个结论？

表格、事件/日志列表；显示字段、行与必要的筛选，超出容量允许内部滚动。

1×3的简短事件摘要只作入口，不冒充完整明细。
