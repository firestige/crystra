# 出口、同面端口与纵向标题验证

2026-09-11。横向暂可用版本已保存于 [阶段标记](CHECKPOINTS.md)。当前在该快照上验证同面端口选择和纵向 fork/join 标题避让；尚未将实验规则冻结到正式设计。

## 实际做法

冻结原 ELK 结果的节点位置、容器、真实接口，以及不参与选择的连线。对同一真实作用域内的返回线，枚举源与目标的四个连接面：一条线 16 种组合，两条线联合 256 种组合。每个组合交给 libavoid 同时生成完整路线，然后统一评分。

透明拼装接缝不再截断参与评估的返回线；真实容器边界仍是硬约束。横向保持标记版本的节点几何；纵向先让文字包围盒参与 ELK 布局，再冻结该布局进行出口选择，没有实现新的图布局算法。上一版构图仍可能受它当时的端口假设影响，不能把本实验说成节点与路线的全局联合最优。

每个面除原有固定间隔端口外，还提供对端中心投影、障碍物安全边界投影等有限候选。同一类原生 ShapeConnectionPin 允许 libavoid 选择位置。每个连接面组合同时保留原单端口方案参与评分，防止原生目标函数与外部评分差异引入退化；一条返回线比较两种端口模式，两条比较四种。这里只穷举连接面及模式，未穷举连续端口位置。窄 fork/join 只检查同一面的占用间隔。

纵向 fork/join 标题使用浏览器测量的文字尺寸，以 ELK 外置左侧标签参与布局，并作为返回路由的障碍物。渲染器使用布局给出的文字框坐标；并非用背景遮住穿过文字的连线。当前样本文字已测量，未知标题使用保守估算，正式集成仍需随字体与文本重新测量。

硬检查：端点存在且连接准确、正交、不得穿节点或标签、不得离开真实作用域、目标箭头前有至少 24px 直线。路由器使用 28px 障碍缓冲。

完整路线的实验代价：

| 项目 | 权重 |
|---|---:|
| 与固定线或同批候选线的严格交叉 | 每次 100000 |
| 共线重叠长度 | 每单位 10000 |
| 与其他线小于 12px 的间隔缺额积分 | 每单位 100 |
| 拐弯 | 每次 80 |
| 路径长度 | 每单位 1 |
| 端口偏离面中点 | 每单位 1.1 |

没有为 WEST 或其他连接面加优待分。相同代价时按稳定枚举顺序择一；这是确定性 tie-break，不是增量编辑稳定性策略。代价和阈值是可调整的实验政策，不是已证明的最优常数，也不是一个完整物理斥力场。

## 结果

- 三套真实样本的 56 个状态中，有 32 次作用域评估，共 512 个连接面候选。多个状态重复包含同一局部几何，不能称为 512 个不同业务场景。
- 本轮候选中，开发“澄清缺口”、系统设计“调整方案”、科研管理的两类补救返回线，横向均自动选出 WEST → SOUTH，且所检查的横向完整展开状态没有同分并列。这与上一版人工规定的结果一致，但现在由候选代价选出。
- 遮挡反例中，固定 WEST → SOUTH 仍可行，长度 724、3 次拐弯、代价 964；自动选 NORTH → EAST，长度 456、1 次拐弯、代价 536。
- 几何旋转后能换出口；改名不改变路线。两个返回关系的联合 256 组合也做了验证。
- 路由结果与各自布局种子 `routingSeeds` 的节点、真实接口、边界点和非目标线段逐项相同；横向节点还与标记版本逐项相同。纵向布局种子因文字避让而重新计算。选中路线没有新增严格交叉或共线重叠。
- 科研管理纵向旧几何上的返回线从三次拐弯降到一次，证明端口选择可以独立解决台阶，无需移动节点。
- 七个路由与文字框测试通过。另两套场景的 24 个状态在真实浏览器中复核，18 张截图、进入/折叠/恢复焦点及实际 SVG 文字范围检查通过。

## 查看与复现

打开 `preview.html`，顶部切换“端口与标签改进 / 已标记基线”。“遮挡反例”可直观看到出口换面；三套原样本用于确认已有画面保持可用。

```sh
node build.cjs
node --test route-choice.test.cjs
node verify-browser.cjs
node verify-other-scenarios.cjs
```

`route-choice.cjs` 是组合评估与 libavoid 调用；`candidates.json` 保存 512 个候选的有效性、拒绝原因、路线、分项和总分；`counterexamples.json` 保存反例；`layouts.json` 保存标记基线、当前布局种子与改进结果；`pinTrials` 记录每个连接面候选下的端口模式试验。

## 边界

已作为当前优先候选接入 v8 预生成样本，完整规则见 [候选规范](../../../components/workflow-map-layout-candidate.md)。尚未合入产品动态布局运行时。本轮支持同一真实作用域内至多两条、端点为矩形活动或 fork/join 的无标签返回线。非矩形端点、返回线标签重定位、跨真实容器边界和更大连线集合明确拒绝，尚未泛化。

同批返回线联合交给路由器，并相对冻结的其他线评分；路由器不会为了候选反过来移动那些固定线。若所有出口都不合格，当前会报告失败，不偷偷重排节点或降级约束。没有验证大图性能、交互编辑的稳定性惩罚或全局最优。

依赖复用第一轮实验的 libavoid-js 0.5.0-beta.5，没有新增产品依赖。

生成 v8 候选资产：`node export-v8.cjs`；适配回归：`node --test v8-candidate.test.cjs`。
